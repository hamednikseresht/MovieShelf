Welcome

MovieShelf turns a plain list of movie file names into a searchable movie library on your PC: posters, ratings, cast, quality, duplicates and problems, with nothing to upload. Your list stays yours; the app only reads it.

What you get

  • Every movie matched to IMDb: English and original titles, year, rating, cast, directors, genres, runtime. Optional Rotten Tomatoes and Metacritic scores.
  • Fast search and filters with an advanced search language, grouping, sorting and saved views.
  • Quality tools: file quality is read from the name (and, optionally, from the real file), duplicates and weak spots are listed under Problems.
  • Your own data: favorites, watched, ratings, notes, a wishlist, backups.
  • Export to Excel with the movies and columns you choose.

How it works

  1. You keep one or more .txt files with one movie name per line (for example Heat.1995.1080p.BluRay).
  2. The app reads each name, finds the title, year and quality in it, and matches it to IMDb using the IMDb datasets stored on your PC.
  3. It then adds details (cast, posters, scores). Names it cannot match with confidence appear in Problems so you can confirm them.
Your files are never changed. The app never renames, moves or deletes a movie file. Where an action touches the disk (the rename plan) it writes a script for you to read and run yourself.

Setup guide

What you need

ItemDetails
WindowsWindows 10 version 1809 or later, or Windows 11, 64-bit. Nothing else needs to be installed first.
Disk spaceAbout 200 MB for the program. The IMDb data and the title index take about 3 GB more; keep about 4 GB free.
InternetSetup itself needs none. The IMDb data (about 1.9 GB) is downloaded by Setup if you choose it, or on the first start, unless you load a backup that holds it.
Your listA folder with one or more .txt files, one movie per line (not needed when you load a backup).

Step by step

  1. Run MovieShelf-Setup.exe and follow the wizard: it checks your system, shows the licence, and asks where to install, which optional packages to download and which shortcuts to add. Then it starts MovieShelf. Administrator rights are needed only for an install for all users.
  2. Choose how to start. The first time MovieShelf opens it asks:
    • Load a backup: pick a full backup (.zip) made on this or another PC. The library, settings, API keys, list files and posters come back; anything the backup does not hold (such as the IMDb data) is downloaded afterwards.
    • Start with the defaults: choose the folder that holds your .txt list. MovieShelf downloads the IMDb data, matches your list and fetches posters. Plan for about 10 to 20 minutes; the progress bar shows how far it is, and finished parts are kept if you close the app. The IMDb files go to %LOCALAPPDATA%\MovieShelf\data\imdb. The Stop button on the progress bar stops an update at once (a half-downloaded file is removed; finished files and results are kept, and the next update continues).
  3. Open MovieShelf later from the Start menu or the desktop shortcut.

What Setup does

#StepWhat it does
1System checkChecks the Windows version, 64-bit, free disk space, memory and internet, and notices a library you already have.
2ProgramInstalls MovieShelf into the folder you choose. .NET and the Windows App SDK are included, so nothing else is installed.

MovieShelf-Setup.exe /S installs without asking anything.

If something goes wrong

  • Setup names any failed step on its last page. A failed optional download does not stop the install: the app downloads the IMDb data itself on the first update.
  • Full details are in install.log in the program folder (Setup) and %LOCALAPPDATA%\MovieShelf\data\native.log (the app).
  • Windows may warn that the setup file is from an unknown publisher. Choose More info, then Run anyway, if you trust where you got it.

Updating to a new version

Your library, posters, IMDb data and settings are in %LOCALAPPDATA%\MovieShelf, so an update only swaps the program. Optional: Settings → Maintenance → Save full backup…. Run the new MovieShelf-Setup.exe: it finds the installed version and upgrades it in place. The library is upgraded on the first start; nothing is lost and nothing big is downloaded again.

Moving to another PC

Run MovieShelf-Setup.exe on the new PC. To bring everything over (library, favorites, notes, settings, API keys, list files, posters), use Settings → Maintenance → Full backup → Save full backup… on the old PC and Load full backup… on the new one.

Removing MovieShelf

Open Windows Settings → Apps → Installed apps, and choose Uninstall beside MovieShelf. The wizard asks what to keep. Your library, backups, settings, posters and IMDb data are all kept unless you choose to delete them.

Filters (left)

Sections for Library, Genre, Year, Ratings, Runtime, Quality, Type and Country. Each section shows how many of its filters are on. Click a chip to switch it on; click again to switch it off. Reset all clears every filter. Your filters are remembered between runs (not the search text).

Results bar

At the top, All / Movies / Series picks the section. Series holds the TV series and mini-series of your library (the poster shows the years it ran and the length of an episode); Movies holds the rest. The filters, search, sorting and counts all work inside the chosen section, which is remembered between runs. Then the count of movies shown, then Group, Sort and the reverse button, the poster / table switch, Select, Export and Watch next. Active filters appear as removable tags under it.

Posters and the table

Each poster shows the IMDb rating, resolution (4K, 1080p, …), badges such as FA (Farsi dubbed), RT / MC scores, a warning icon if the match needs a check, and heart / tick marks for favorites and watched. In table view click a column heading to sort; click it again to reverse.

Finding movies

The search box

Type words: all of them must match somewhere in the title (English, original or Persian), cast, directors, file names, genres or year. It ignores accents and capitals.

year:1990-1999, year:>2005, year:<=1980A range, or after / before a year.
rating:>8, rt:>=90, mc:>=75, votes:>100kIMDb rating, Rotten Tomatoes, Metacritic, votes. A bare number means “at least”.

dir:nolan, actor:"tom hanks", writer:People.
country:, lang:, type:, collection:Place, language, kind, franchise.

Combine freely, for example genre:drama year:>=2000 rating:>7.5 -war is:unwatched. Each operator shows as a tag under the search box; click its cross to remove it. Click the ? button for clickable examples.

Filters, grouping and sorting

  • Filters narrow the list; several chips of one kind all have to match (for genres) or any may match (for qualities).
  • Group by decade, year, genre (first listed), rating band, quality, type, first letter or watched. Click a group name to fold it.
  • Sort by title, year, ratings, votes, length, recently added or your own rating. The arrow button reverses the order.

Saved views

Set up a search, filters, sort and grouping, then Saved views → Save the current view. Click a saved view to apply it; the cross deletes it.

The movie window

Click a poster or table row. You see the poster, titles (English, original, IMDb, Persian), ratings (IMDb, Rotten Tomatoes, Metacritic), runtime, genres, plot, cast and crew, and your files.

  • Favorite and Watched buttons, a 1–10 star rating and a notes box (saved as you type). Watched stores the date.
  • Click a cast member, director, writer or crew name to open their profile: photo, birth and death, birthplace, professions, biography (in Persian too, when TMDB has it) and their movies grouped by job (Actor, Director, Writer, Producer, Composer, Cinematographer, Editor and others). The movies in your library come first as posters; the person's other movies are listed below with a Wishlist button. Show all in the library filters the library by the person. The photo, biography and other movies need a TMDB key; without one you still get the IMDb facts and your own movies. Profiles are fetched when opened and kept; Settings → Maintenance → People → Scan people now fetches them in advance for directors and writers, the first five actors, or everyone (an option makes it run after every update).
  • The Persian title comes from TMDB, cleaned up (Persian letters and digits, spaces, half-spaces) and, where TMDB only had Persian in Latin letters, replaced by a reviewed Persian-script title. Click Edit next to it to type your own; Reset brings the stored title back. Your edits are kept in backups. Problems → Other → Persian title lists any that are still in Latin letters.
  • The tomato shows the Rotten Tomatoes score (a red tomato when fresh, 60% or more; a green splat when rotten) and the M badge the Metacritic score. These small icons are drawn for MovieShelf, they are not the official logos.
  • Click a genre or a person to see every movie with them.
  • Your files lists every file for the movie with quality chips (resolution, source, codec, 10-bit, HDR, audio, Farsi dubbed, edition), size, folder and, if read with ffprobe, length, picture size, audio languages and subtitles. Show in folder opens Explorer on the file.
  • Wrong movie? Fix match searches IMDb so you can choose the right one. Your choice is kept for good.
  • Add poster (or Change poster) is for a movie whose poster could not be found or is wrong: choose an image file (JPEG, PNG, WebP or GIF, up to 15 MB), or paste an image address or a file path, then press Use. A poster you add is kept: updates never replace it, and it is part of the full backup. Remove poster clears it. The same button is in Problems → Other → No poster.
  • Remove from list (next to each file) takes that entry out of your library, for example when its folder holds no movie. Your list files and movie files are not changed.

Working with your collection

Select several movies

Click Select, then click movies (hold Shift for a range). The bar at the bottom changes them together: favorite, watched, not watched, rating, add to the wishlist, export just the selection, or Remove from list. Select all results picks everything the filters show. Esc or Done leaves selection mode.

Watch next

The shuffle button picks six movies. Choose the source (current results or the whole library), the kind (Best rated, Surprise me, Hidden gems), a length and a minimum rating. By default only unwatched movies are picked. Watched on a pick marks it and brings another; Pick again reshuffles. The dialog also shows what you watched recently.

Wishlist

A list of movies you want, or want better copies of. Add titles by hand, from the list check, from Problems → Quality, from a selection or from Collections. Mark items found, copy the list, or save it as text or CSV.

Collections

Groups your movies by franchise. With a TMDB key, Check for missing movies shows which parts you do not have; Add missing to wishlist collects them.

Statistics

Totals, decades, genres, directors, actors, qualities and countries. Click a bar to filter the library by it.

Check a list or folder

Use it before adding new movies, or to compare a hard drive with your library. Choose a .txt or .csv file, a folder of movies, or paste names. Nothing changes until you press Add.

Problems

The Problems window has five tabs. The badge on the button counts matching problems, duplicates and titles with no video file.

  • Ignore hides an item until its files change. Show ignored brings them back with a Restore button.
  • Every list can be exported to CSV. When movie folders are set, Duplicates also shows sizes, locations and the disk space wasted by redundant copies.
  • The app never deletes your files: Copy paths to remove puts the names on the clipboard for you to delete yourself.
  • Remove from list (on No video file, or Remove all for the whole tab) hides the title in the library, and no update brings it back. It changes no file and no list file. A title that has a real video in another folder is not reported. Every row in Problems has a Remove from list button; where a row has several files, each file has its own.
  • Episodes of a TV series are not duplicates: files with episode numbers (like S01E02), or a title IMDb lists as a series, go to Duplicates → Series and are not counted. This is a series puts any duplicate there; Not a series brings it back.

Movie folders, ffprobe and the rename plan

Movie folders

Settings → General → Movie folders: one folder per line (or Add a folder…); it is saved and read when you leave the box. The app goes through the folders by itself, finds every movie in them and lists it, and records path and size. Folders are read-only to the app and rescanned on every update.

There are only two places to give the app movies: the movie folders, and the Load list button (a .txt or .csv list, or a folder). One of them is enough. A movie found in a folder goes away when its video does, and Remove from list hides it for good.

Reading the real files (ffprobe)

Tick Read audio languages, subtitles, length and real picture size with ffprobe. Install ffprobe with winget install Gyan.FFmpeg if needed. Each file is read once, again only if it changes. You then get audio and subtitle languages in the movie window and in search (audio:persian), and two new problem lists: Name vs picture and Length differs.

Rename plan

Settings → Maintenance → Rename plan proposes a tidy name for every movie the app has found: the video file, the subtitles beside it, and the folder of the movie (a folder named like the movie that holds only that movie; folders you listed yourself and DVD / Blu-ray folders are left alone). You choose the pattern, for example {title} ({year}) [{res} {src}]: press a field to add it, then Preview. Empty fields vanish with their brackets, and the pattern is kept. It writes a .bat script, a CSV and a list of the new names. Nothing is renamed by the app: read the script, then run it yourself. Items that would get the same name, or a name already taken on disk, are skipped. After renaming, bring the new names in with Load list, because the app finds movies by name.

Export to Excel or CSV

Click Export above the results (or Settings → Maintenance → Export).

  1. Which movies: the selected movies, the current results (with your filters, in the order shown) or the whole library. Narrow down further adds search text, year range, rating, genre, quality or status.
  2. Layout: one row per movie or per file; optionally one Excel sheet per group (uses the Group setting).
  3. File type: Excel (.xlsx) or CSV.
  4. Columns: tick what you need, by group, or use Essentials, Everything, Clear. Your choice is remembered.

The Excel file has a frozen header row, filter buttons, sized columns, clickable IMDb links and a last sheet, Export info, with the date and the filters used. The window shows the number of rows and columns before you export. A normal “Save as” window asks where to put the file.

Updating

  • Scan list & update: adds new lines from your list files, matches them, fetches details and posters. It also runs each time the app starts.
  • Update IMDb ratings: downloads only the small ratings file. Done automatically each week if enabled.
  • Update RT & Metacritic: critic scores from Wikidata (and OMDb with a key). Done monthly if enabled.
  • Retry missing posters, Re-match everything (manual matches are kept) and Re-download IMDb data (1.9 GB) are for repairs.

Full backup (everything)

Settings → Maintenance → Full backup → Save full backup… writes one .zip file with the whole library (every movie, match, detail and score, plus your favorites, notes, views and wishlist), all settings, the API keys, your list files and the posters. The IMDb data (about 3 GB) is optional because it can be downloaded again. The file holds your API keys as plain text, so keep it private (untick API keys to leave them out).

Load full backup… restores it, on this PC or another one. Tick what to restore and press Restore. The library you have now is replaced, but a safety copy of the library, settings and list files is saved first in data\backups\before-restore-…. If the old list or movie folders do not exist on the new PC, the app tells you and points the list folder at the restored list files.

Quick backup (your own data)

Favorites, watched flags, ratings, notes, manual matches, ignored problems, saved views and the wishlist exist only in data\library.db. A copy is saved automatically once a day in data\backups (the last 14 are kept). Export backup saves a file anywhere, Import backup and Restore an automatic backup merge a copy back: nothing is deleted.

Appearance and language

Choose light, dark or system theme, poster size and default layout. The Language button in the top bar (or Settings → Appearance) switches menus and this help between English and Persian. Movie data stays as it is.

Troubleshooting and questions

The window stays empty after the first start.
Either the start-up question is still waiting (choose Load a backup or Start with the defaults), or the first build is running. Watch the progress bar at the top; the build takes about 10 to 20 minutes. Open Settings → Activity log for details.
“No .txt files found”.
Press Load list at the top. You see the duplicates first, then choose to add the names to the current list or start a new list. Nothing is deleted: a new list moves the old list files to a previous lists folder.
A movie has the wrong poster or details.
Open it and use Wrong movie? Fix match. Or look in Problems → Matching.
Many titles show “Needs review”.
The name had no year, or several movies share the title. Confirm them in Problems → Matching; the fixes are kept.
There are no plots, cast photos or Persian titles.
Add a free TMDB key (Settings → Online data), then run Scan list & update.
Rotten Tomatoes and Metacritic are empty for some movies.
Wikidata does not have every score. Add a free OMDb key, then Update RT & Metacritic.
“ffprobe not found”.
Run MovieShelf-Setup.exe again and tick ffprobe, or run winget install Gyan.FFmpeg in a terminal, then restart MovieShelf.
“MovieShelf is already running”.
Only one copy runs at a time. Use the open window, or close it first.
Excel shows strange letters in a CSV.
Use the Excel (.xlsx) format, or open the CSV with “From text/CSV” and choose UTF-8.
I lost my favorites after a problem.
Settings → Maintenance → Backup → Restore an automatic backup and pick a recent date.
Is anything sent to the internet?
Only downloads: IMDb datasets and posters, ratings, critic scores from Wikidata, and (if you add keys) TMDB and OMDb lookups. Your list and personal data stay on your PC.
